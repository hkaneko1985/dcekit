# Data attribution and licensing

## Concrete Slump Test (D7)

I.-C. Yeh, *Concrete Slump Test* [Dataset], UCI Machine Learning Repository,
2007. DOI: https://doi.org/10.24432/C5FG7D.

The UCI dataset is distributed under the Creative Commons Attribution 4.0
International license (CC BY 4.0). The original source files are retained in
`data/raw/` with attribution.

## Simulated datasets (D1-D6)

The cached D1-D6 tables are outputs of the simulator definitions and pinned
public libraries described in `physics_simulators.py`, `PROVENANCE.json`, and
`PHYSICS_ENVIRONMENT.md`. Code in this package is covered by the DCEKit MIT
license. Third-party simulator software, databases, and parameter sets remain
subject to their respective licenses and citation requirements.
