# Input records and distribution scope

`upstream/` contains source-normalized HTEM and, in the author archive, NanoMine records plus retained historical summaries. `cohorts/` contains 5,001 selected Starrydata feature/assignment records and 1,103 PNCExtract records. Historical grids are distinct from the current common API.

`processed/nanomine_audited_records.jsonl` is generated by `src/audit_sources.py` and includes raw source provenance; it is omitted from the public-code archive. The adapter reparses raw source strings and does not trust old unit classifications. `nanomine_selection_manifest.json` lists exact cohorts and semantic hashes. `upstream_manifest.json` identifies current source/aggregate files; original manifests are retained in provenance.

`external_data_manifest.json` states which NanoMine files are excluded from the public-code package, how to restore an authorized matching local copy, and the acquisition limitation. Source notices and field definitions are in SOURCES_AND_LICENSES.md and DATA_DICTIONARY.md.
