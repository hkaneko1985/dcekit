# Historical version 0.2.0 evidence

These configurations, results, and verification documents preserve the earlier revision for traceability. Version 0.2.1 in the repository root corrects that experiment, preserves the 300 selected source pairs, and records new mask-key audits and supplementary interpretation results. Detailed historical raw-value audit rows are included only in the author archive.
