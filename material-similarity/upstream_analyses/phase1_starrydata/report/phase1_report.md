# 材料類似度研究 Phase 1 実施報告

**版:** 1.0.0  
**解析日:** 2026-09-07  
**対象:** 目的変数・専門家判断を用いない、組成・形態・合成工程メタデータによるクラスタリング  
**判定:** 事前登録どおりでは **CONDITIONAL GO**、運用上は **注意事項付きで Phase 2 の外部再現へ進む**

## 1. 結論

Phase 1 の主解析、反証分析、複数シード再現、クラスタ解像度感度分析を完了した。

- 組成のみの F0 に対し、形態と合成・製造工程を加えた F2 は、同一 `SID`（同一論文レコード）の弱い既知正例をクラスタ内へより強く濃縮した。
- 主解析の共所属リフトは F0 の **1.54** から F2 の **3.45** へ上昇した。差の対数リフトは **0.809**、論文ブロック・ブートストラップ95%区間は **[0.780, 0.837]** だった。
- F2 の増分は、組成完全一致対だけに限定した解析、形態・工程がともに観測された完全ケース、工程値の組成層内シャッフル、論文等重み、一論文ずつの除外、3シード、8クラスタ解像度で方向が維持された。
- F2 の再標本化安定性は Adjusted Rand Index 中央値 **0.918** で、事前基準0.70を上回った。
- 一方、単一論文が F2−F0 の共所属変化に占める最大寄与は **15.5%** で、事前登録した10%未満を満たさなかった。また、欠損パターンだけでもリフト **3.21** が得られ、論文・入力様式の影響は大きい。

したがって、Phase 1 は6基準中5基準を満たす。これは「F2が科学的な材料類似度として確立した」という判定ではない。**Starrydata内部で、工程メタデータを含む表現が弱い文脈支持を再現するという証拠が得られたため、HTEMによる独立な Phase 2 に進める**という判定である。

## 2. 研究上の問いと主張範囲

本解析の問いは次のとおりである。

> 目的変数を使わずに定義した材料間距離に形態・合成工程を加えると、組成距離だけの場合より、同じ研究文脈に置かれた材料をクラスタ内へ濃縮できるか。

同一論文は真の類似度ラベルではない。同じ論文に遠い対照材料が入る場合があり、異なる論文にも非常に近い材料がある。このため、同一 `SID` は**弱い既知正例**、異なる `SID` は**未ラベル**として扱った。未ラベル対を負例とは扱っていない。

Phase 1 から主張しない事項は以下である。

- 物性値を予測できること
- ある材料での改善効果を別材料へ転移できること
- クラスタが唯一の自然な材料分類であること
- 異なるクラスタの材料が科学的に非類似であること
- 専門家の材料分類と一致すること

## 4. 類似度とクラスタリング

### 4.1 特徴量セット

| セット | 特徴量 |
|---|---|
| F0 | 組成 |
| F1 | F0 + 物理形態 |
| F2 | F1 + 合成・製造工程 |
| F3 | F2 + 純度・相対密度・粒径 |

組成距離は、元素比 L1、周期表族の分布 L1、周期の分布 L1、元素集合 Jaccard をそれぞれ0.50、0.25、0.15、0.10で統合した。カテゴリは統制語彙化した集合の Jaccard 距離、連続値は5–95%範囲で頑健に尺度化した距離を用いた。

観測可能なブロックだけを等重みで平均し、欠損罰則は0とした。すなわち、欠損していること自体を科学的な類似特徴にはしていない。ただし、どの項目が記載されるかというパターンが情報源を表し得るため、欠損のみの反証モデルを別途評価した。

平均連結法による凝集型クラスタリングを用いた。主解析のクラスタ数候補は25, 50, 75, 100, 150で、開発集合のシルエットと最大クラスタ率から選んだ。F0–F3はいずれも150が選ばれた。

### 4.2 実装監査で修正した点

階層クラスタリングでは、距離が完全に同じペアの結合順が入力行順に依存し得る。初期実装では選択後の行が `SID` 順に並ぶ余地があり、同一論文の連続配置がタイブレークを通じて見かけの共所属を作る可能性を検出した。

最終実装では次を行った。

1. `(SID, sample_id)` の独立SHA-256ハッシュで行順を固定した。
2. 欠損のみモデルでは、同一欠損マスクを恣意的に分割せず、観測マスク署名そのものをクラスタとした。
3. 入力順反転に対する選択・行順不変性テストを追加した。
4. 修正前の結果を破棄し、主解析、2つの追加シード、解像度感度分析をすべて再実行した。

本報告の数値はすべて修正後のものである。

## 5. 主解析結果

同一 `SID` ペアの共所属率を、組成距離を層別マッチした異なる `SID` の未ラベル対の共所属率で割った値を共所属リフトとした。

| 特徴量 | 同一SID共所属率 | 未ラベル共所属率 | 共所属リフト（95%区間） | 安定性 ARI 中央値 |
|---|---:|---:|---:|---:|
| F0 | 97.16% | 63.13% | 1.54 [1.52, 1.55] | 0.962 |
| F1 | 95.73% | 30.96% | 3.09 [3.03, 3.14] | 0.972 |
| F2 | 95.29% | 27.58% | 3.45 [3.36, 3.54] | 0.918 |
| F3 | 94.07% | 22.60% | 4.16 [4.03, 4.28] | 0.887 |

F2では同一論文ペアの絶対共所属率がF0よりわずかに低い一方、組成をそろえた未ラベル背景の共所属率が大きく低下した。その結果、弱い既知正例の**相対的濃縮**が高くなった。これは「すべての同一論文試料を一つにまとめた」という結果ではなく、工程・形態が異なる背景材料をより細かく分けながら、同一論文ペアの大部分を保持した結果である。

増分比較は次のとおりだった。

| 比較 | 対数リフト差 | 論文ブロック95%区間 |
|---|---:|---:|
| F1 − F0 | 0.698 | [0.677, 0.714] |
| F2 − F0 | 0.809 | [0.780, 0.837] |
| F2 − F1 | 0.111 | [0.089, 0.131] |
| F3 − F0 | 0.995 | [0.963, 1.023] |
| F3 − F2 | 0.186 | [0.174, 0.196] |

組成層別置換検定はF0–F3のすべてで経験的 **p = 0.001** だった。1,000回置換の最小到達値であり、0とは報告しない。

## 6. 反証・感度分析

| 検査 | 結果 | 解釈 |
|---|---:|---|
| 組成完全一致対のみ | F0リフト1.00、F2リフト2.07、F2−F0区間 [0.694, 0.747] | 元素組成が同じ場合にも形態・工程が区別に寄与 |
| Form・工程の完全ケース | F0 1.40、F2 3.97、F2−F0区間 [1.012, 1.081] | F2の効果をブロック欠損だけでは説明できない |
| 工程を組成層内シャッフル | F2リフト2.85（実データ3.45） | 工程の具体値は寄与するが、形態や情報源構造も残る |
| 欠損パターンのみ | リフト3.21 | 記載様式・情報源交絡が大きい |
| 論文等重み | F2−F0対数リフト差0.813 | 大きい論文のペア数だけによる結果ではない |
| 一論文ずつ除外 | 266回中、方向反転0 | 特定の一論文を除くことで主方向は消えない |
| 単一論文の最大絶対寄与 | 15.54%（基準10%未満） | **唯一の事前基準未達** |

欠損のみリフトがF2に近いことは重要である。F2は欠損のみを上回り、完全ケースでも増分が残るため、結果全体が欠損だけで生じたとはいえない。しかし、同一論文という支持情報の一部が論文ごとの入力様式を捉えていることは否定できない。Phase 2では、別スキーマ・別収集系でこの交絡が再現されるかを検証する必要がある。

### 7.2 解像度

事前登録した25–150クラスタに、事後的な境界感度分析として200, 250, 300を追加した。F2は8/8解像度でF0を上回った。

ただし、開発集合の内部基準は拡張後も上限300を選んだ。したがって、今回の範囲内では一意の「自然なクラスタ数」や安定な最適点は同定できない。主結論は150クラスタの一点推定ではなく、**F2の増分方向が複数解像度で一貫すること**に置く。200–300は事後感度分析であり、主解析を置き換えない。

## 8. クラスタの記述的プロファイル

専門家ラベルや事後採点は行っていない。代わりに、F2クラスタについて、クラスタ形成に使った特徴の頻度だけを機械的に集計した。これは解釈補助であり、妥当性検証には使っていない。

例として、次のまとまりが得られた。

- 157試料のクラスタ: Formの100%が `film`、工程の98.1%が `filmgrowth`
- 125試料のクラスタ: Formの100%が `ribbon`、工程の100%が `melting`
- 596試料のクラスタ: Formの99.0%が `powder`、工程上位は `solgel`, `mechanicalalloying`, `hydrothermal`
- 571試料のクラスタ: Formの99.8%が `bulk`、Bi–Te系組成と `pressuresintering` が多い

これらは距離が入力特徴を反映していることの点検にはなるが、「科学的に正しいクラスター」の証明ではない。全150クラスタの集計は `results/phase1_cluster_profiles.json` に保存した。

## 9. Phase 2 判定

| 事前基準 | 結果 |
|---|---|
| F2/F3のF0に対する増分95%区間下限 > 0 | PASS |
| 組成完全一致除外後も正方向 | PASS |
| 5解像度中4以上で正方向 | PASS（5/5、拡張では8/8） |
| 安定性ARI中央値 ≥ 0.70 | PASS |
| 単一論文の最大寄与 < 10% | **FAIL** |
| 欠損のみリフト < F2 | PASS |

厳密な事前登録判定は **CONDITIONAL GO** である。補助解析により、論文等重みでも増分が正で、一論文を除外しても方向が反転せず、完全ケースでも効果が残ることを確認した。しかし、事前登録した10%基準を事後的に緩和してPASSとはしない。

運用判断としては、**Phase 2へ進む**。理由は、Phase 2がまさにStarrydata固有の論文・欠損・入力様式への依存を独立データで反証する段階だからである。

## 10. Phase 2 への凍結仕様

Phase 2 は HTEM を用いる外部再現とし、次を解析前に固定する。

### 10.1 データと弱い支持情報

- 解析単位: HTEM試料
- 主たる弱い既知正例: 同一 sample library / study 内の試料対
- 補助情報: owner / contributor。異なる所有者は負例にしない
- 研究機関: HTEM内で識別力が乏しい場合は評価しない
- 開発・確認分割: sample library / study 単位。グループをまたいで試料を分割しない
- 未ラベル対: 異なる library / study から組成を層別マッチして抽出

同一ライブラリID、study ID、owner、ファイル名、行順、装置ランIDは特徴量に入れない。

### 10.2 凍結する特徴セット

- F0: 組成のみ
- F1: F0 + 物理形態。HTEMで形態が一定なら情報量なしとしてそのまま報告
- F2: F1 + 成膜・合成工程、基板、熱処理等の工程カテゴリ
- F3: 構造・形態情報が十分にある場合だけ探索的に追加

Phase 1のF2を主候補とする。Phase 2の支持ラベルを見てから工程語彙・重み・クラスタ数を調整してはならない。スキーマ変換表は支持ラベルを隠した状態で作成する。

### 10.3 必須解析

1. F0/F1/F2の平均連結クラスタリングと同一ライブラリ共所属リフト
2. ライブラリ・ブロック95%ブートストラップ
3. 組成層別置換検定
4. 組成完全一致対と組成非完全一致対の分離解析
5. Form・工程の完全ケース
6. 工程値の組成層内シャッフル
7. 欠損マスクのみモデル
8. ライブラリ等重みと一ライブラリずつの除外
9. 独立行順ハッシュを少なくとも3通り用いたタイ感度
10. 事前固定した複数解像度での方向一貫性

### 10.4 Phase 2 の確認的成功条件

- F2−F0対数リフト差のライブラリ・ブロック95%区間下限が0を上回る
- 完全ケースと組成非完全一致対でも方向が正
- F2が欠損のみ、および工程シャッフルを上回る
- 事前固定した解像度の少なくとも80%でF2 > F0
- 再標本化ARI中央値が0.70以上
- 単一ライブラリの最大絶対寄与が10%未満
- 一ライブラリ除外で主方向が反転しない

10%基準を満たさない場合は、Phase 1と同様に条件付き判定とし、群サイズに適応した代替基準を事後採用しない。

## 11. 残る課題

1. **代理情報の妥当性:** 同一論文・同一ライブラリは類似性の正解ではない。
2. **情報源交絡:** 欠損のみモデルの高いリフトが示すように、入力様式を学習する余地がある。
3. **工程の粗さ:** 現在はカテゴリ集合であり、温度、時間、雰囲気、工程順序を十分に表現していない。
4. **領域の混在:** プロジェクト別ファイルではなく全サンプル代替コホートを使ったため、材料領域が混在する。
5. **一意なクラスタ数:** 内部基準が探索上限に達し、自然な解像度は未同定である。
6. **機関情報:** Starrydataサンプル表に機関情報がなく、同一機関・異論文解析は実施していない。
7. **物性との関係:** 目的変数を用いない設計なので、性能予測・改善転移は未検証である。

## 最終判断

Phase 1 は、形態・合成工程を含むF2表現が、組成だけのF0より同一論文という弱い文脈支持を一貫して濃縮することを示した。一方で、論文寄与集中と欠損・情報源交絡が残る。

よって、**F2を凍結した主候補として Phase 2 の HTEM 外部再現へ進む。ただし、Phase 1単独では材料類似度の科学的妥当性を確定しない。**
