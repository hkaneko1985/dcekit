# Starrydata attribution and source conditions

Source: https://starrydata.org/utility/terms.html (checked 2026-09-13).
Project paper: https://doi.org/10.1080/27660400.2025.2506976.
Dataset repository: https://github.com/starrydata/starrydata_datasets.

This research distribution contains a selected, normalized cohort derived from Starrydata, not an official Starrydata database release. The project rules request citation of its paper when publishing results or derived datasets, and original experimental papers where practicable. Do not present this derived cohort as a copy of the official service. Source identifiers are preserved. No MIT license is assigned to the source data.

The original all-samples snapshot was recorded upstream as 2026-09-06. Use `(SID, sample_id)` as the sample key. The full-source file was not recovered; the included table is the historical selected feature/assignment artifact, not a new current download.
